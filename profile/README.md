# NestJS Microservicios

Proyecto de práctica del curso **NestJS + Microservicios** (Udemy), construido paso a paso por Renato Ortega.

## Servicios

- `products-ms`: microservicio de productos (Prisma + SQLite)
- `client-gateway`: API Gateway (próximamente)
- `orders-ms`: microservicio de órdenes (próximamente)
- `payments-ms`: pagos con Stripe (próximamente)

**Stack:** NestJS · TypeScript · Prisma · NATS · Docker · PostgreSQL
